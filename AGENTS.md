# SportsBook

Email service summarizing latest sports results for specified teams.
Early experiment ("vibecoding"). Single initial commit.

## Tooling

- **Package manager**: `uv` (not pip). Lockfile: `uv.lock`.
- **Python**: 3.14 (`.python-version`)
- **Dependencies**: none yet. Add with `uv add <package>`.
- **Run**: `uv run python main.py` (entrypoint: `main()` in `main.py`)

## What's missing (as of initial commit)

No tests, lint, format, typecheck, or CI config. Only `.gitignore` (ignores `.DS_Store`).
